# 🀄 麻雀與食飯抽水結算系統 — 網頁版

打麻雀、食飯、抽水、中途換人、成組人一齊找數，全部喺瀏覽器計晒，唔使安裝、唔使登入。

👉 **線上使用：<https://cheong18.github.io/mahjong-calculator/>**

> 另有 iPhone App 版（同一份程式碼，用 Capacitor 包裝）：cheong18/mahjong-calculator-ios（私人 repo）。

---

## ✨ 功能

### 🐷 人員設定
- 每個人有名稱同相片；未輸入名稱唔可以新增。
- 相片可以裁剪（拖動、縮放），輸出 320×320，頭像清晰。
- **組別**：長按人員頭像拖去另一個人上面即可組成一組；組別可以指定**隊長** 👑，組名同組相片跟隊長。
- 人員格仔顯示佢入咗邊一台，或者「齋食飯」。

### 🀄 麻雀台
- 新增麻雀台要**揀齊 4 位**人員先可以確定。
- 每個座位輸入贏輸，每台輸入抽水。
- 🔄 中途換人：揀接替嘅人，原本座位贏輸保留。
- 刪除麻雀台前有**確認視窗**。
- **一個人同一時間只可以入一台**：已入座嘅人要先被 🔄 換走，先可以去第二台或同一台另一個位置（揀人視窗會鎖住已入座嘅人）。
- 座位撳 × 會先問確認；正選座位刪走後變**空位**，撳 ＋ 揀人補位（一台要有 4 人，空位會有紅字提示）。
- 贏輸、抽水、飯錢輸入框只出**數字鍵盤**；贏輸嘅正負用旁邊「±」掣切換。
- 每台自動檢查：**所有人贏輸總和 + 抽水 = 0**，唔對路會喺該台方格底部提示。

### 🍲 飯錢
- **齋食飯名單**：淨係食飯、冇打麻雀嘅人（已入座嘅人唔可以列入）。
- **飯錢計算方法**：「參與抽水補貼」或「無抽水補貼（純計飯錢）」。
- **已付食飯錢記錄**：邊個出咗幾多。

### 📊 結算
- 個人明細：贏輸、飯錢、付飯錢、最終結果（+ 收 / − 付）；名字欄只顯示頭像，令手機唔使左右移動。
- 表格可以左右捲動，名字欄固定。
- **建議找數方式**：按組別加總後配對轉賬，例如「Eddie 付 $11.25 給 👉 Sam」。

### 📊 當日積分圖
- 「建議找數方式」下面：中間線係人名，左邊紅棒 = 負數（輸），右邊綠棒 = 正數（贏）；只顯示有打麻雀嘅人。

### 💾 儲存今日積分 + 📈 累積統計
- 分享掣下面有「💾 儲存今日積分」（會先問確認），同一日再儲存會取代。
- 「人數設定」方格底部「📈 累積統計」：下拉選單揀人，睇累積積分折線圖（打直 = 積分，打橫 = 日期，日期多可左右滑動）。
- 統計以**人名**對應，改名之後會當成另一個人。

### 📤 一鍵分享 PDF 報告
- 產生包含**日期**同頁面所有內容嘅 PDF（齋食飯、已付飯錢、每台麻雀枱、個人結算、建議找數方式）。
- 版面為手機設計，字體大，開啟後唔使放大；每個方格完整喺同一頁。
- 手機瀏覽器會彈出系統分享選單（WhatsApp 等）；電腦瀏覽器會直接下載 `Mahjong-Report_日期_時間.pdf`。
- 另有「只複製文字摘要」。

## 💾 資料儲存

- 資料只存喺**你自己部裝置、嗰個瀏覽器**嘅 localStorage（key：`mahjong-calc-v1`）。
- **唔會上傳**去 GitHub 或任何伺服器，所以：
  - 換電腦／手機／瀏覽器開同一條連結，會見到全新資料（空白開始）。
  - 朋友開你條連結，見唔到你嘅資料。
  - 清除瀏覽器網站資料會令資料消失；iPhone Safari 長時間唔用亦可能被系統清走。
- 累積統計（`history`）同人員、麻雀枱一齊存喺同一個 key。
- 頁底「**清空全部**」會刪走所有人員、相片、麻雀枱、食飯記錄同累積統計。
- 頁底「**匯出 / 匯入**」：匯出 `Mahjong-Backup_日期.json`（包括所有人員連相片同累積統計），可匯入另一部裝置；匯入會**取代**現有全部資料。換機或清除瀏覽器資料前建議先匯出備份。

## 🧮 結算邏輯

1. 每台 `Σ贏輸 + 抽水 = 0`。
2. `差額 = 已付食飯錢總額 − 總抽水`。
3. 差額 > 0：
   - **參與抽水補貼**：所有參與者平分差額。
   - **純計飯錢**：齋食飯者各付 `總飯錢 ÷ 總人數`；打牌嘅人平分餘下部分。
4. 差額 ≤ 0（抽水多過飯錢）：多出嘅錢退返畀打牌嘅人平分。
5. `最終結果 = 贏輸 − 飯錢 + 付飯錢`。
6. 按組別加總，再配對債主同欠債組別計出轉賬。

## 🛠 開發同部署

純靜態網站，由 GitHub Pages 從 `main` 分支根目錄發佈，冇後台、冇建置步驟。

```
.
├── index.html                # 全部畫面、樣式同邏輯（單檔）
├── tailwind.css              # 編譯後 Tailwind CSS（取代原本 CDN）
├── vendor/
│   ├── html2canvas.min.js    # 轉圖（已修補，見下）
│   └── jspdf.umd.min.js      # 產生 PDF
└── README.md
```

本機試用：直接用瀏覽器開 `index.html` 即可（或用任何靜態伺服器）。

### 注意事項
- `tailwind.css` 係由 App 版 repo 用 Tailwind CLI 編譯出嚟（`npm run build:css`），**唔好手改**。改過介面之後要重新編譯再覆蓋。
- `vendor/html2canvas.min.js` 係**修補過嘅版本**：原版喺 iPhone WebKit 計錯文字基線，令 PDF 文字偏低；修補係令 `fillText` 用 `fontBoundingBoxAscent` 計基線（檔尾有註解）。
- 網頁版同 App 版用同一份 `index.html`；App 版額外有 Capacitor 原生分享（網頁版偵測唔到 Capacitor 就用瀏覽器分享／下載）。

### 部署新版本
```bash
git checkout -b my-change
# 修改 index.html（必要時更新 tailwind.css / vendor/）
git commit -am "..."
git push -u origin my-change
# 喺 GitHub 開 Pull Request，Merge 入 main，約 1–2 分鐘後上線
```
